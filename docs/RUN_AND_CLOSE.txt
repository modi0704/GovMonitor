GOVMONITOR - START, UPDATE AND CLOSE THE APP ON A WINDOWS PC
===========================================================
Do these steps in order. Copy one command at a time.

BEFORE YOU START
1. Open Docker Desktop. Wait until it says "Engine running".
2. Open "Git Bash" (or PowerShell).
3. Go to the GovMonitor folder. Change the path if you put it somewhere else:

   cd /d/BARMM/govmonitor

   (In PowerShell: cd D:\BARMM\govmonitor)


A. START THE APP (EVERY DAY)
   docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d

   Then open your browser at:  http://localhost:8000/
   Sign in. The app opens on "Step-by-step". Follow the steps.


B. GET THE NEWEST VERSION (WHEN YOU ARE TOLD THERE IS AN UPDATE)
   git pull
   docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --build

   Your saved data is kept. The update can take a few minutes.


C. SET UP YOUR REAL AGENCY (ONLY ONCE)
   docker compose -f deploy/docker-compose.yml --env-file deploy/.env exec web entrypoint.sh manage initialize_workspace

   It asks for your agency's name, a short code, your name and your email.
   It shows a temporary password ONE time. Write it down privately.
   Sign in with it and choose your own password when asked.
   The practice (demo) agencies are switched off. Nothing official is deleted.
   Do not use the demo email addresses after this.


D. CLOSE THE APP (YOUR DATA IS KEPT)
   Press Save in the app, sign out, then run:

   docker compose -f deploy/docker-compose.yml --env-file deploy/.env stop

   Closing the browser alone does NOT stop the app.
   Start it again later with step A.


IF SOMETHING GOES WRONG
Is the app running?
   docker compose -f deploy/docker-compose.yml --env-file deploy/.env ps

Show the last error messages (send these to your IT person):
   docker compose -f deploy/docker-compose.yml --env-file deploy/.env logs --tail 80 web worker db

"Access is denied": make sure Docker Desktop is open and running, then try again.

NEVER add "-v" to a docker command and never delete Docker "volumes":
that erases all saved data.
