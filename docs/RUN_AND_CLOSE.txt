GOVMONITOR - START, UPDATE AND CLOSE THE APP ON YOUR PC
======================================================
1. Open Docker Desktop. Wait until it says "Engine running".
2. Open Git Bash.
3. Go to your GovMonitor folder (use your own folder; keep the quotes):

   cd "/d/BARMM PROJECT/GovMonitor"

Then use ONE of these commands:

   ./run.sh start     Start the app. Wait for "GovMonitor is running",
                      then open http://localhost:8000/ in your browser.
                      No sign-in needed: the app opens straight away.

   ./run.sh stop      Close the app. Your data is kept.

   ./run.sh update    Get the newest version and start it.

   ./run.sh demo      Load the practice data (done for you automatically
                      the first time, when the database is empty).

   ./run.sh status    See whether the app is running.

   ./run.sh logs      Show the last messages (send these when asking for help).

Closing the browser does NOT stop the app. Use ./run.sh stop.


NO SIGN-IN - ONE PERSON, ONE PC (THE DEFAULT)
The app opens without a sign-in page: you are the only user and you enter
every office's figures yourself. Only this PC can open it: other computers
on the network cannot.

Bring the sign-in page back later (if the app is ever shared):
   ./run.sh login on
Switch it off again:
   ./run.sh login off

With sign-in ON:
   Practice account:  admin@sample-ministry.demo  /  demo-password-2026
   Forgot the email or password?
      ./run.sh reset-password              lists the administrator emails
      ./run.sh reset-password YOUR-EMAIL   gives that account a new temporary password


IF IT SAYS "the database ... refused its password" OR "run ./run.sh fix-db"
   ./run.sh fix-db
This makes the saved database use the same passwords as your settings.
All your data is kept. It happens when the app was started before with
other settings (for example from another copy of the folder).


IMPORTANT
- Use only ONE GovMonitor folder on this PC. Every copy shares the same
  saved data in Docker, so starting another copy can cause the error above.
- Never delete Docker "volumes" and never add "-v" to a docker command:
  that erases all saved data.


SET UP YOUR REAL AGENCY (ONLY ONCE, WHEN YOU STOP PRACTISING)
   ./run.sh setup

It asks for your agency's name, a short code, your name and your email, and
shows a temporary password ONE time (you need it only when sign-in is on).
The practice agencies are switched off; nothing official is deleted.
Without sign-in the app then opens as your real agency's administrator.
